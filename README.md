# 🍳 Receitas do Jhonny

Site de receitas simples e responsivo desenvolvido com HTML, CSS e JavaScript.

## 📦 Estrutura do Projeto

```
receitas-do-jhonny/
├── index.html      # Página principal
├── style.css       # Estilos CSS
├── script.js       # Lógica JavaScript (receitas, busca, etc.)
└── server.js       # Servidor local de desenvolvimento
```

## 🚀 Como executar localmente

### Opção 1: Abrir diretamente no navegador

Abra o arquivo `index.html` no seu navegador preferido.

### Opção 2: Servidor local

```bash
node server.js
```

Em seguida, acesse: `http://localhost:3000/index.html`

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- Node.js (apenas para o servidor local de desenvolvimento)
